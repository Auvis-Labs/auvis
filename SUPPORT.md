# Getting Support for Auvis

Welcome! If you are using **Auvis** and need help, have a question, or ran into a bug, here is where to find answers and get assistance.

---

## 💬 Community Channels & Discussions

### 1. GitHub Discussions (General Questions & Ideas)
For Q&A, setup help, configuration advice, and architectural ideas:
👉 **[GitHub Discussions](https://github.com/cridiv/Auvis/discussions)**

- **Q&A**: Ask how to structure policy YAML files, resolve identity headers, or configure connectors.
- **Ideas & RFCs**: Propose new destination connectors or feature enhancements before writing code.

---

## 🐛 Bug Reports & Feature Requests

### 2. GitHub Issues (Bugs & Feature Requests)
If you found a reproducible bug or want to request a specific technical feature:
👉 **[Open a GitHub Issue](https://github.com/cridiv/Auvis/issues/new/choose)**

Before submitting:
- Search existing open and closed issues to check if someone else reported it.
- Include your Auvis version (`auvis version`), OS, and relevant policy snippets (with real secrets removed).

---

### 3. Security Reports (Do NOT post publicly)
