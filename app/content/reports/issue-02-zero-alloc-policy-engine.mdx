## 1. Why `encoding/json` Becomes a Bottleneck

Go's standard `encoding/json.Unmarshal` allocates heavily because it reflects across map types and constructs interface values for every nested JSON primitive.

When evaluating rules like `mask email` or `pseudonymize patient_id`, we don't need to parse the entire document tree into Go structs. We only need to locate the target keys, rewrite the matching byte ranges, and emit the governed output.

<Callout type="tip" title="Byte-Level Token Scanning">
By scanning raw byte streams and doing in-place replacement for fixed-width or padded tokens, we bypass struct allocation completely.
</Callout>

```go
// Buffer pooling in transform pipeline
var bufPool = sync.Pool{
    New: func() any {
        return bytes.NewBuffer(make([]byte, 0, 4096))
    },
}
```
